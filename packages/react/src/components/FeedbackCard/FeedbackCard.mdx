# FeedbackCard

A rating and comment prompt for collecting feedback on the wayfinding
experience.

## Usage

Use it at a natural pause, not mid-task:

- After arrival, when a route has completed
- At the end of a session
- Following a support interaction

Do not interrupt active navigation with it. A feedback prompt over live guidance
is the wrong trade.

`isSubmitting` and `successMessage` drive the three states. Success replaces the
form rather than disabling it — leaving a greyed-out rating behind a
confirmation suggests the rating is still editable.

`onSubmitFeedback` receives the rating and the comment together, so there is no
partial-submit state to reconcile.

## Accessibility

- Success replaces the form, so nothing reads as still editable after
  submitting.
- The in-flight state must be announced; a dimmed button alone is not sufficient
  for a screen reader user.
- The rating control owns its own accessible value, so the current rating is
  readable without inspecting the stars.
