# MapOverlay

A positioned surface that floats product chrome above the map canvas.

## Usage

Use it for anything that sits over the map rather than beside it:

- A search bar anchored to the top of the canvas
- A route summary along the bottom edge
- Floating controls and status chips

Do not render map content inside it. The canvas is renderer output; an overlay
is the app's own UI layered on top.

Pass `collisionInsets` from the map adapter. Overlays that ignore them end up
covering the renderer's attribution, which is usually a licensing requirement,
not a cosmetic preference.

`width` is a t-shirt scale on web. On native the host lays the overlay out with
frame and modifier sizing instead, which is recorded as intentional in the
variant analyzer rather than counted as a parity gap.

## Accessibility

- The overlay adds no landmark of its own; its content keeps its own reading
  order and roles.
- Contrast comes from the surface token, not from the basemap underneath, so
  legibility does not depend on what the map happens to be showing.
- Respect `collisionInsets` so overlays never cover attribution or the
  renderer's own controls.
