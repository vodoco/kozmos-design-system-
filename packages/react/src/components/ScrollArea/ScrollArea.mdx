# ScrollArea

A scrollable region with consistent scrollbar treatment across platforms.

## Usage

Use it where content must scroll inside a bounded box rather than moving the
page:

- A quick-access row of categories beside a map
- A long option list inside a panel
- Any pane with its own independent scroll

Give vertical scrolling a bounded height and horizontal scrolling a bounded
width. Otherwise it grows to fit its content instead of scrolling.

`viewportProps` addresses the inner, keyboard-focusable viewport. Use it for a
meaningful region name, keyboard handlers or viewport-specific styling. The
forwarded ref and ordinary HTML props still address the outer wrapper.

`hideScrollbar` hides the bar but keeps the region scrollable. Reach for it only
where another affordance makes scrolling obvious — a peeking next item, for
instance — since a hidden scrollbar removes the main cue that there is more.

`snap` is web-only. Native needs a different container entirely, not a flag:
Compose requires a Lazy list with `rememberSnapFlingBehavior`, and SwiftUI
paging is iOS 17+ while the package targets iOS 16. This is recorded as
intentional in the variant analyzer rather than treated as a parity gap.

## Accessibility

- The region is keyboard scrollable, so it does not depend on a pointer or a
  visible scrollbar.
- `hideScrollbar` removes the visual cue but not the behaviour; pair it with
  another affordance so the content does not appear to end at the fold.
- Do not nest scroll areas on the same axis — the inner one traps the wheel and
  keyboard, which is disorienting.
