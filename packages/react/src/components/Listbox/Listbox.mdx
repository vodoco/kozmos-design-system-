# Listbox

An always-visible list of selectable options, in single or multiple mode.

## Usage

Use it when the options should stay on screen rather than hide behind a trigger:

- A filter panel beside results
- A settings pane where the current choice should always be readable
- The list body inside a larger composed control

If the list should collapse to a trigger, use `Select`, `Combobox`, or
`MultiSelect` — those own their own popover. `Listbox` is deliberately just the
list, so it composes inside them and inside your own surfaces.

`onValueChange` receives the new value and the option that caused the change. In
`multiple` mode the value is an array; in single mode it is a string. Read the
mode from your own state rather than inferring it from the value's type — an
array of one is ambiguous otherwise.

import androidx.compose.runtime.*

import com.kozmos.components.listbox.KozmosListbox

@Composable

        maxHeight = 280.dp
    )
}

## Accessibility

- Renders as a listbox with `option` children, so selection state is announced
  rather than inferred from styling.
- Arrow keys move the active option and Home / End jump to the ends; selection
  in single mode follows focus.
- `maxHeight` scrolls the list rather than clipping it, keeping every option
  reachable by keyboard.
