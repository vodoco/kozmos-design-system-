# Modern UI Component Inventory

## 1. Foundations
Primitives that form the basis of the system.
- **ThemeProvider**: Context provider for theme tokens.
- **Box**: Low-level layout component (div/View).
- **Stack**: Flexbox/AutoLayout container (VStack, HStack).
- **Grid**: 2D layout system.
- **Container**: Content width constraint.
- **Typography**: Text, Heading, Display, Caption.
- **Icon**: SVG icon component.

## 2. Actions
Components that trigger an action.
- **Button**: Standard interactive element.
- **IconButton**: Button reduced to an icon.
- **FloatingActionButton**: Primary screen action (FAB).
- **SplitButton**: Button with a primary action and a dropdown.
- **ToggleButton**: Two-state button.
- **SegmentedControl**: Linear set of two or more segments.

## 3. Inputs
Components for user data entry.
- **Input**: Single-line text field (TextField).
- **Textarea**: Multi-line text field.
- **Select**: Dropdown selection (Picker).
- **Checkbox**: Binary choice.
- **Radio**: Mutually exclusive choice.
- **Switch**: Toggle switch.
- **Slider**: Range selection.
- **Rating**: Star/numeric rating.
- **FileUpload**: File selector/dropzone.
- **DatePicker**: Date selector.
- **TimePicker**: Time selector.
- **Search**: Search input field with specific styling.
- **OTPInput**: One-time password input.

## 4. Navigation
Components for moving between views.
- **Tabs**: Tabbed interface.
- **Breadcrumb**: Path-based navigation.
- **Menu**: Dropdown/Context menu.
- **Sidebar**: Vertical navigation drawer.
- **BottomNavigation**: Mobile bottom bar.
- **Stepper**: Progress through a sequence.
- **Pagination**: Navigate through pages of data.
- **Link**: Hyperlink.
- **Navbar**: Top application bar.

## 5. Feedback
Components that provide status/feedback.
- **Alert**: Static status message (Callout).
- **Toast**: Transient notification (Snackbar).
- **Progress**: Loading indicator (Linear/Circular).
- **Skeleton**: Loading placeholder state.
- **Spinner**: Indeterminate loading state.
- **Dialog**: Modal window.
- **Drawer**: Slide-out panel (Sheet).
- **Backdrop**: Dimmed background layer.

## 6. Data Display
Components for presenting information.
- **Table**: Data grid.
- **List**: Vertical list of items.
- **Card**: Container for related content.
- **Avatar**: User/Entity image.
- **Badge**: Small status indicator.
- **Tag**: Categorization label (Chip).
- **Tree**: Hierarchical list.
- **Timeline**: Events in chronological order.
- **Tooltip**: Hover/press information.
- **Popover**: Content overlay on trigger.
- **Accordion**: Expandable content sections.
- **Separator**: Divider line.

## 7. Pointr Specific
Custom components for mapping context.
- **MapView**: Map container.
- **WayfindingCard**: Navigation instruction.
- **FloorSelector**: Level picker.
- **POICard**: Point of interest details.
- **LocationPin**: Map marker.
- **DirectionStep**: Navigation step.
- **BottomSheet**: Pull-up panel (common in maps).
