## 1 · What this workstream is, and how Olcay works

**What.** Kozmos is a four-platform design system in one monorepo: React (`packages/react`), design
tokens (`packages/tokens`, Style Dictionary → CSS / iOS / Android), SwiftUI (`packages/ios`), Compose
(`packages/android`), a Vue wrapper (`packages/vue`), and a Figma library of 94 component sets
generated by a local plugin (`figma/foundations-importer/code.js`, ~1.9 MB). Figma is not drawn by
hand: a plugin paints it, and Code Connect pins each set's node ID to the code.

**How Olcay works** — treat as the default mode:

- The standing instruction, repeated most turns:
  > "Once more, please analyse extensively to see if anything is overlooked, missed, mis-implemented
  > or could have done better. No hacks - no cheats - do it propertly and perfectly. Otherwise
  > please proceed with your recommendation. Provide me everything I'd need if I need to make
  > changes myself. But remember you have CLI access. I don't want to miss anything"
- **Verify by measuring; never assert from memory.** Every claim in a report should have the command
  that produced it. Assertions that turned out false have cost real time — see §7.
- **Adversarial self-audit before saying "done".**
- Decisions as short multiple-choice questions, recommended option first.
- **Mistakes stated plainly**, including your own, in the commit and the report.
- Pushes, PR edits and merges only on a go-ahead. "Open a PR" never means "merge it".
- Commit messages and PR bodies here are long and narrative — they explain _why_, and name what is
  still unverified. Match that register.

## 7 · Traps that have cost real time here

**The checkout is shared with a live second session.** It switches branches under you (HEAD moved
from `codex/wave-2-figma-components` to `codex/wayfinding-map-panel` mid-task on 2026-09-09) and
leaves work uncommitted in the tree. **Stage explicit file paths — never `git add -A` or a
directory.** A directory-wide stage swept another session's work into my commits twice. To build or
split branches without disturbing their tree, use `git worktree add` in a scratch directory; never
reset or rewrite a branch they are on.

**The shell is zsh, not bash.** A command stored in a variable does not word-split (`$G merge …`
runs a program literally named `git -c core.hooksPath=…`), `PIPESTATUS` is always empty (it is
`$pipestatus`), and an unquoted glob inside a flag aborts the command (`--include=*.swift`). For
anything multi-step, write a Node script that calls `execFileSync("git", [args])` — no shell,
nothing to split.

**Figma runs stale plugin code.** It reads a development plugin's files at launch. ⌘Q and relaunch
after every change to `code.js`.

**Never press Rebuild.** It mints new node IDs and Code Connect pins the old ones. Update preserves
them.

**A quiet Figma file is not a stalled run.** `lastModified` can sit still for forty minutes while a
bulk run works; the only honest signal is a jump in saved sets after a silence. Quitting to "unstick"
it throws the work away — I advised that twice and was wrong both times.

**A bound property ignores the painter.** A variable-bound node property renders the variable, not
the painter's write. Fix the token table.

**GitHub does not retarget a stacked PR for you** unless the base branch is deleted. Merging a
stacked PR without retargeting lands it in the base branch, not `main`.

**A check that names its consumers can only confirm what someone already looked at.** Three separate
gaps hid behind that shape. Scan everything; name only the exceptions.

**Workflows: cap the fan-out.** A scope audit fanned three refuters onto ~330 candidates, hit the
1000-agent cap, burned 5.16M tokens and exhausted usage credits, losing 970 agents. Cap the candidate
list before multiplying it, and prefer a grep over three agents voting on "does this already exist?".

## 9 · How to verify anything here

```bash
pnpm tokens:elevation:check && pnpm tokens:border:check && pnpm tokens:radius:check \
  && pnpm tokens:typography:check && pnpm tokens:contrast:check && pnpm tokens:raw:check \
  && pnpm figma:plugin:check && pnpm components:contract:check && pnpm figma:stamp:check \
  && pnpm docs:snippets:check
```

```bash
pnpm native:check          # Swift + Kotlin compile, ~6s. Android needs one gitignored line:
                           # echo "sdk.dir=$HOME/Library/Android/sdk" > packages/android/local.properties
```

```bash
pnpm figma:verify          # reads the live Figma file; needs FIGMA_ACCESS_TOKEN in .env
pnpm tokens:radius:nesting # ditto; concentric radii
```

A fresh `git worktree` has no built workspace packages, so `pnpm --filter @kozmos/react test` fails
to resolve `@kozmos/icons` until you run `pnpm --filter "@kozmos/react..." build`. That failure is
the worktree, not the code.
